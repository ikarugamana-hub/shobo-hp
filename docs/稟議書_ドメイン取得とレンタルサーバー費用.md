## 1. 結論(ご承認いただきたい事項)

消防向けサイト(現在 GitHub Pages で公開中)を、当社の独自ドメイン配下で正式運用するため、
**ドメイン取得およびレンタルサーバー契約(初年度の外部支払額 概算 13,200円〜15,180円・税込)**の承認をお願いしたい。

**この金額は事業者に支払う料金のみであり、移行作業費・保守費は含まない(別途 要見積)。**
移行作業の対象範囲は「6. 懸念事項」に記載のとおり、旧URL 41箇所の修正を含む。

ただし、承認に先立ち **下記2点の確認が必要**である。

1. **希望アドレスの綴りの確認(綴り違いの可能性が高い)**
   ご指定のアドレスは `www.unielase.jp/shobo/` であるが、**本サイト内のリンクを全数調査した結果、
   当社ドメインは `unilease.co.jp` であり、`unielase` という綴りは1件も使用されていない**
   (2026年7月25日確認。`unilease.co.jp` への参照は28箇所)。
   したがって `unielase` は `unilease` の綴り違いと推測されるため、**取得前に正式な綴りの確定が必要**。
   誤った綴りで取得した場合、費用が無駄になるうえ、ブランド表記の不統一を招く。

2. **既存ドメイン(`unilease.co.jp`)の活用可否**
   既存の当社ドメインのサブディレクトリ(`www.unilease.co.jp/shobo/`)で公開できる場合、
   **ドメイン費用・サーバー費用がいずれも不要**となる可能性がある(下記 B案)。
   本サイトから既存コーポレートサイトの各ページ(`/contact/`、`/privacy/`、会社案内PDF等)へ
   リンクしていることから、**同ドメイン上に稼働中のサイトが存在することは確認できている。**
   ただしサーバー仕様・CMSの構成・ファイル追加の権限については情報不足のため、要確認。

### B案:既存ドメイン `unilease.co.jp` のサブディレクトリで公開

- 新規ドメイン取得費用・サーバー契約費用が **不要**(既存契約の範囲内で対応できる場合)
- URL は `www.unilease.co.jp/shobo/` となり、当社サイトとして最も自然
- **前提条件:** 既存サイトのサーバーにファイルを追加できる権限・仕様であること(現時点で情報不足)
- **確認すべき点:** 既存サイトには CMS が導入されていると推測される
  (本サイトから `unilease.co.jp/cms/footerPDF/` 配下のPDFへリンクしているため)。
  CMS がURLの振り分けを管理している場合、静的ファイルをサブディレクトリに追加できるかは
  構成に依存するため、既存サイトの制作・保守業者への確認が必要。

### C案:GitHub Pages を継続し、独自ドメインのみ設定

- ホスティング費用 0円、ドメイン費用のみ
- **制約1(パス):** ご希望の `/shobo/` をそのまま実現するには、独自ドメインを GitHub Pages 側に設定した上で、
  リポジトリ構成または名称の変更が必要。現在のリポジトリ名は `shobo-hp` のため、
  標準的な構成では公開パスが `/shobo-hp/` となり、`/shobo/` にはならない。
  既存サーバー側で転送設定(リバースプロキシ)を行う方法もあるが、別途構築が必要。
- **制約2(既存サイトとの併用):** 同一ホスト(例 `www`)上で、既存Webサイトとパス単位で共存させることは
  DNS設定だけではできない。
- **メールは併用可能:** Web用のレコード(A/CNAME)とメール用のレコード(MX)は別に設定するため、
  GitHub Pages を利用してもそのドメインのメールは通常どおり利用できる。
- **代替案:** `shobo.(ドメイン名)` のような専用サブドメインにすれば、
  既存サイトと干渉せず GitHub Pages のまま独自ドメイン化できる(ただしご希望のアドレス形式とは異なる)。

## 6. 懸念事項・リスク・前提条件

**必ず対応が必要な技術的事項(移設時の修正対象)**

現在のサイトには GitHub Pages 用の旧URL(`/shobo-hp/`)が **7ファイル・計41箇所**含まれている
(2026年7月25日にリポジトリ内を全数確認)。移設時は下表すべての修正が必要。

| 種類 | 該当ファイル(箇所数) | 修正しない場合の影響 |
|---|---|---|
| ルート相対パス `/shobo-hp/...` | `404.html`(11) | フォント・favicon・ロゴが読み込まれず、リンクも切れる(**表示が壊れる**) |
| 絶対URL(canonical・OGP・JSON-LD・印刷用URL) | `index.html`(5)、`kansen.html`(9)、`sp.html`(3)、`story_cleaning.dc.html`(9) | 検索結果・SNS共有時に旧URLが表示され続ける |
| 絶対URL | `robots.txt`(1)、`sitemap.xml`(3) | 検索エンジンに旧URLを通知し続ける |

- **QRコードの再生成が必須(確認済み)。** `images/site-qr.png` をデコードして検証した結果、
  旧URL `https://ikarugamana-hub.github.io/shobo-hp/` が埋め込まれていた(2026年7月25日確認)。
  このQRコードは `kansen.html` と `story_cleaning.dc.html` の **印刷用フッター**に配置され、
  隣にURLテキストも併記されているため、**QR画像とURLテキストの両方を差し替える必要がある。**
  なお、このQRコードを印刷して配布済みの資料がある場合は、
  移設後も旧URLが参照されるため、**旧URLから新URLへの転送設定を行うか、資料を差し替えるかの判断が必要。**
- 移設先サーバーで `404.html` をエラーページとして返す設定が必要(サーバーによって設定方法が異なる)。
- 旧URLから新URLへの転送(リダイレクト)を行うか否かの方針決定が必要。
- 移設後は全ページの表示確認が必要。

**費用・契約面のリスク**

- 記載の料金は 2026年7月25日 時点で確認した **概算・参考値** であり、確定金額ではない。
  申込時点の料金は各社公式サイトで再確認すること。
- サーバー料金はキャンペーン価格の場合があり、期間終了後に変わる可能性がある
  (確認した価格は 2026年7月6日〜8月4日 のキャンペーン適用価格との記載あり)。
- ドメインの更新料金は、事業者によって「サービス維持調整費」等の名目で追加費用が加算される場合がある。
  一部事業者は 2026年7月1日から 26.50% の調整費を適用しているとの情報があるが、**要確認**。
- 支払いは契約期間分の一括前払いとなる場合がある。
- ドメインは **更新を失念すると失効し、第三者に取得される可能性がある**。更新管理の担当者を定めること。

**その他の前提条件**

- 月間アクセス数を1,000件以下と想定。この規模であれば容量・転送量は充足する見込みだが、
  **「1,000件」が訪問者数・ページ閲覧数・動画再生回数のいずれを指すかを明確にする必要がある**(要確認)。
- サイト内に動画ファイルを含み、公開ファイルの総量は約8MBある。
  動画の再生率やブラウザのキャッシュ状況によって転送量は変動するため、
  契約前に容量・転送量・同時接続数・バックアップ仕様を各社の仕様書で確認すること(**要確認**)。
- 表示速度については実測していないため、案ごとの優劣は判断していない。

## 7. 推奨案

**まず B案(既存ドメイン `unilease.co.jp` のサブディレクトリ)の可否を確認し、可能であれば B案を推奨する。**
新規費用が発生せず、URL も当社サイトとして最も自然なため。

**B案が採用できない場合は A案(新規ドメイン+レンタルサーバー)を推奨する。**
初年度の外部支払額は概算 13,200〜15,180円(税込)であり、外部費用の水準としては妥当と考える。
ただし、いずれの案でも移行作業(旧URL 41箇所の修正を含む)は同様に発生するため、
作業を社内で行うか外部に委託するかを併せて決定する必要がある。

C案は外部費用が最も安いが、ご希望の `/shobo/` というアドレス形式を実現するには
リポジトリ構成の変更または転送設定の構築が必要となるため、
アドレス形式を優先する場合は適さない。
なお専用サブドメイン(`shobo.(ドメイン名)`)で妥協できる場合は、C案が最も低コストとなる。
