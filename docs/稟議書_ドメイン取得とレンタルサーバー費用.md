## 1. 結論(ご承認いただきたい事項)

消防向けサイト(現在 GitHub Pages で公開中)を、当社の独自ドメイン配下で正式運用するため、
**ドメイン取得およびレンタルサーバー契約(年間 概算 13,200円〜15,180円・税込)**の承認をお願いしたい。

ただし、承認に先立ち **下記2点の確認が必要**である。

1. **希望アドレスの綴りの確認**
   ご指定のアドレスは `www.unielase.jp/shobo/` であるが、当社の既存ドメインは `unilease.co.jp`(社内メールアドレスのドメイン)である。
   `unielase` は `unilease` の綴り違いの可能性があるため、**取得前に正式な綴りの確定が必要**。
   誤った綴りで取得した場合、費用が無駄になるうえ、ブランド表記の不統一を招く。

2. **既存ドメイン(`unilease.co.jp`)の活用可否**
   既存の当社ドメインのサブディレクトリ(`www.unilease.co.jp/shobo/`)で公開できる場合、
   **ドメイン費用・サーバー費用がいずれも不要**となる可能性がある(下記 B案)。
   既存サイトのサーバー仕様・管理体制について情報不足のため、要確認。

## 6. 懸念事項・リスク・前提条件

**必ず対応が必要な技術的事項**

- 現在のサイトは GitHub Pages 用に `/shobo-hp/` というパスを前提とした絶対パス指定が含まれている
  (例:`404.html` 内のロゴ画像・各リンク)。
  `/shobo/` に変更する場合、**該当箇所の修正が必須**。修正しないとロゴが表示されず、リンクも切れる。
- 移設後は全ページの表示確認が必要。

**費用・契約面のリスク**

- 記載の料金は 2026年7月25日 時点で確認した **概算・参考値** であり、確定金額ではない。
  申込時点の料金は各社公式サイトで再確認すること。
- サーバー料金はキャンペーン価格の場合があり、期間終了後に変わる可能性がある
  (確認した価格は 2026年7月6日〜8月4日 のキャンペーン適用価格との記載あり)。
- ドメインの更新料金は、事業者によって「サービス維持調整費」等の名目で追加費用が加算される場合がある。
  一部事業者は 2026年7月1日から 26.50% の調整費を適用しているとの情報があるが、**要確認**。
- 支払いは契約期間分の一括前払いとなる場合がある。
- ドメインは **更新を失念すると失効し、第三者に取得される可能性がある**。更新管理の担当者を定めること。

**その他の前提条件**

- 月間アクセス数を1,000件以下と想定。この規模であればサーバー性能・転送量は問題にならない見込み。
- サイト内に動画ファイルを含むため、アクセス数が想定を大きく超える場合は転送量の再確認が必要。
